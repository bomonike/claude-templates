Question 1:
What does an MCP Tool primarily do in Claude Code?

Options:
a. Replaces sub-agents
b. Acts as an interface between Claude and external tools
c. Handles file versioning

Correct Answer: b.

📝 Additional Info:
MCP Tools connect Claude Code to third-party systems or APIs, letting it perform actions like testing or data fetching seamlessly.




Question 2:
Which of the following best describes the MCP architecture?

Options:
a. Local script → IDE → Compiler
b. Client ↔ Host ↔ Server
c. LLM → Database → Web UI

Correct Answer: b.

📝 Additional Info:
MCP uses a client-host-server model where Claude (the client) communicates with an MCP host that connects to external tools or APIs.

Question 5:
When should you use an MCP Tool instead of a sub-agent?

Options:
a. When you need Claude to collaborate with another AI model
b. When connecting Claude to an external system or API
